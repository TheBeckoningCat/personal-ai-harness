# Launcher templates

These are **text templates**, not programs. This zip has no `.command` or `.bat` files.

After first-run, the Startup guide may replace package-root `START HERE.md` with `daily-START-HERE.txt` and save the installer under `Building/Basement/Archive/First run/`.

Offer a computer-specific launcher only if they ask, and only as a `.txt` they save themselves.
