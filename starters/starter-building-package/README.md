# New Building Starter Package v0.2-public

**If you are an AI:** your first visible reply is the use notice in `USE NOTICE.md` (or the same text in `START HERE.md`). Print it in full. Then open `START HERE.md`. If they can only paste one file, ask for `START HERE.md` next.

**If you are a person and the chat cannot take a folder:** paste `START HERE.md` into the chat and say **Start Here** or **go**. The guide will ask for the next file by name.

**Beta:** this is a betta-test public release. Chatbot / batch-drag markdown is the primary path; optional launchers are not required. See `PUBLIC_README.md`.


This folder is a reusable skeleton. Copy `Building/` to hatch a new project vault. Everything important lives in markdown on {{OWNER}}'s machine.

A new Building starts with two named people, an Inbox, a Cases floor, empty Departments, and communication files already installed. It does not start with another Building's mission, cars, or leftover files.

This is a **hatch checklist + Building skeleton**, not a one-click AI Campus. See [[PUBLIC_README]] and [[HONEST_LIMITS]].

## Version

v0.2-public — sanitized public release of the v0.2 skeleton. Pattern drawn from other live Buildings; no household examples are required models.

## Default floors

| Floor | Path | Job |
|---|---|---|
| Ground | `Building/Main Lobby/` | Map, mission, rules, directory |
| Live | `Building/Inbox/` | {{OWNER}} drops paper; the Director files it |
| Live | `Building/Cases/` | Named jobs with cover sheet, Originals, and Derived |
| Offices | `Building/Offices/` | Named Architect and named Director after hatch |
| Mail | `Building/Mail Room/` | Board, occupant Mail Boxes, clerk placeholder |
| Conference | `Building/Conference Room/` | Live Work Table, Docket, How We Talk |
| Shop | `Building/Departments/` | Empty on hatch |
| Basement | `Building/Basement/` | Archive and long-term reference |

## Default seats

Only two on hatch.

- **Architect** — designs this Building; on a multi-Building campus, may send shared-edge architecture mail to your vault architect (optional campus seat, not required day one)
- **Director** — owns the local work; on a multi-Building campus, owns the Building's Town Hall door for consequence mail to your campus operations secretary (optional campus seat, not required day one)

## Boot loop

2. Boot Instructions and Access Boundaries
