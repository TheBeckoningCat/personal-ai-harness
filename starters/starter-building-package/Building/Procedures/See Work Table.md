# Procedure: See Work Table

Working personas run this when they receive: See Work Table for new updates and comments.

This command is not a ping. A ping is stay-awake only.

## Do not

- Do not write Talk or a board item only to confirm receipt.
- Do not discuss a parked Docket sheet.
- Do not write from a doorbell or Mail Clerk seat.
- Do not mark {{OWNER}}'s Close.

## Sequence

1. Stay in the open working session.
2. Read [[Conference Room/README]] far enough to see the live sheet.
3. Read [[Main Lobby/Current Period]].
4. Open that Work Table sheet.
5. Read Status, the question, newest Talk, then Decision and Sign-off if present.
6. Ask: does this topic need a real remark from this Role right now?
7. If no, write nothing.
8. If yes, write under Talk in High School English. Newest first. Date it. Sign it. `@Name` only when that person must act.
9. Stay inside this Role.

## Done when

The persona has read the live sheet and has either written a real remark or has correctly written nothing.
