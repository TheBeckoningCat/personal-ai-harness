# Procedure: Make a Case

Use this after the Work Table has agreed that named work belongs in {{BUILDING_NAME}} as a Case.

## Do not

- Do not open a Case from chat, mail, or a Docket sheet that has not been moved to the Work Table.
- Do not copy official next-action tickets onto a Cover Sheet.
- Do not make a Department on the same day you open the Case. A Department comes later, and only when the first job has left work that will still need a home.
- Do not write Current state if you are not {{DIRECTOR_NAME}}. Do not write Notes if you are not {{OWNER}}.

## Sequence

1. {{OWNER}} names the Case. He may draft it on the Work Table. Everyone else sends a topic request to The Docket.
2. {{DIRECTOR_NAME}} decides whether the work belongs in {{BUILDING_NAME}} and whether it should be a Case or stay an unfiled question.
3. If it is a Case, {{ARCHITECT_NAME}} places `Cases/<name>/` with `Cover Sheet: <name>.md`, `Originals/`, and `Derived/`.
4. The cover sheet records Named by {{OWNER}}, Chaired by {{DIRECTOR_NAME}}, and Placed by {{ARCHITECT_NAME}}.
5. {{OWNER}} writes dated Notes. {{DIRECTOR_NAME}} writes Current state. {{OWNER}} drops unsorted papers in `Inbox/`. {{DIRECTOR_NAME}} files them into `Originals/`, not into Notes. Inbox is not current state.
6. If leftover papers already live somewhere else in this Building, {{ARCHITECT_NAME}} moves them into that Case's Originals so they are not a second home. They do not copy them.
7. Your campus operations secretary (optional multi-Building campus seat) is told only when a date, a wait, or a commitment must live in the campus record. For a solo Building, keep that commitment local or in {{OWNER}}'s own system. {{DIRECTOR_NAME}} owns that Director route when Town Hall is wired.

## Later

When the first job is done enough that this household will still need the folder, {{DIRECTOR_NAME}} agrees it should live under Departments. {{ARCHITECT_NAME}} then moves the whole folder there, including the cover sheet, Originals, and Derived. They do not leave a second copy in Cases. How that move works is in [[Departments]].

## Done when

The Case folder exists, the cover sheet names the three seats, Originals have one home, and {{DIRECTOR_NAME}} can write Current state.
