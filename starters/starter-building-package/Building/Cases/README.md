# Cases

One folder per named operating case. How a Case is made is [[Procedures/Make a Case]]. The case file lives at the top of that folder and is named `Cover Sheet: <case name>`. Originals go in `Originals/`. Derived work goes in `Derived/`.

{{OWNER}} drops unsorted paper in `Inbox/`. {{DIRECTOR_NAME}} files originals into the case `Originals/` folder. Do not treat Inbox as current state.

{{OWNER}} writes comments, questions, and extra information in **Notes** at the bottom of that case's Cover Sheet. Newest first. Date it. Sign it. Do not write in Current state. {{DIRECTOR_NAME}} lifts anything that changes what is true into Current state. Originals still go in `Originals/`, not pasted into Notes.

This is not a Department. A Case is one named job. When the remaining work is a cycle that does not end, the folder moves to `Departments/`. A Case that has ended takes its folder to `Basement/Archive`.

Official next actions and dates stay wherever {{OWNER}} already keeps them (for example a personal action system). Do not copy those tickets onto a Cover Sheet. Getting Things Done (David Allen) may be an influence; do not brand this Building as GTD.

No live Cases on hatch. {{DIRECTOR_NAME}} opens the first one when {{OWNER}} names work that belongs here.
