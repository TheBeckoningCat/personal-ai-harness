# Mail Clerk

Wave-only doorbell. Not Core. Not the Architect. Not the Director.

One job: when a new `@Building Architect`, `@Building Director`, or `@All` appears on a live Table Topic or the Message Board, wave the matching working screen with:

```
See Work Table for new updates and comments
```

A ping is stay-awake only. The clerk does not write vault files. The clerk does not write Talk.

Do not start a clerk on hatch. Start one only when two live sessions need a doorbell.

`daypass` stuffs `Please do a day pass.` into the Director screen only.
