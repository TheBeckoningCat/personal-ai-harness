# Pathway Map — Domain

**Campus teaching alias:** Building

**Status:** Public wording revision (structure originated by Artemis; Sec. Gen. voice; jobs restored 2026-09-28)  
**Audience:** Agent-primary; owner-openable.  
**Stack:** Personal AI Harness → Operational Hub → Domains

This map describes jobs and pathways agents should follow inside one Domain. Campus labels are teaching aliases only.

## 1. Boot order

1. Read this Pathway Map.
2. Read `Access Boundaries.md` and `Operating Rules.md`.
3. Read `Boot Instructions.md` and `Start Here.md`.
4. Read Mission for direction only.
5. Open assigned Role before Persona shells.
6. Check Left on the Desk.
7. Review Work Table and Docket before opening Cases.

## 7. How this Domain attaches to the Hub

A Domain operates beside an Operational Hub, not instead of one.

The Hub owns cross-domain organization. The Domain owns specialized work.

Building is optional clothing. The jobs are the structure.

## 8. What this map is not

- Not secret circuitry.
- Not a one-click life OS.
- Not a requirement to use Campus or Building labels.
- Not permission to invent Cases or bypass Access Boundaries.
- Not the Operational Hub.

The Pathway Map is guidance showing how the pieces connect.
