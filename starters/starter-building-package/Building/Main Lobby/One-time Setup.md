# One-time Setup

The Architect fills this sheet once after the skeleton is copied. Do not hatch a second time from this page. When the values below are written, apply them through [[How to Hatch a New Building]] and stop.

## Apply once

1. Write the table above.
2. Replace the matching placeholders in the copy.
3. Rename the office folders, Mail Box folders, and Public Filing Cabinet folders to the Architect name and the Director name.
4. Create Role and Persona files named for those two people.
5. Complete Mission, Access Boundaries, Staff Directory, and — if you have a campus Town Hall — Town Hall Connection from this table.
6. Prove both Town Hall mail routes **only if** Town Hall is wired. For a solo Building, skip.
7. Leave Inbox and Cases empty except their README files. Leave Departments empty.
8. If {{OWNER}} named a first Work Table topic, create that sheet. If not, leave the Work Table empty.
9. Do not add a second Communication Standard file.
10. Do not copy another Building's Departments, mission, or leftover files.

When those steps are done, this sheet is a record of the hatch. Do not keep filling it as ordinary work.
