# Building Directory

This Building is organized by rooms and directories. Use the table as a map. It is not a boot sequence.

| Floor | Room | Path |
|---|---|---|
| Ground | Main Lobby | `Main Lobby/` — [[Main Lobby/Start Here]], [[Main Lobby/Boot Instructions]], [[Main Lobby/Access Boundaries]], Personas, [[Main Lobby/Campus Communication Standard]], and [[Main Lobby/AI Host and Context Glossary]] |
| 2 | Offices | `Offices/Building Architect/`, `Offices/Building Director/` — rename these folders to {{ARCHITECT_NAME}} and {{DIRECTOR_NAME}} at hatch |
| 3 | Mail Room | `Mail Room/` — Mail Boxes at `Mail Room/Mailboxes/Architect/` and `Mail Room/Mailboxes/Director/` until renamed to the occupants; Public Filing Cabinet; packet formats; and [[Mail Room/Town Hall Connection]] |
| 4 | Conference Room | `Conference Room/` |
| Live | Inbox | `Inbox/` — {{OWNER}} places new material here, and {{DIRECTOR_NAME}} files it. The Inbox is not authoritative current state. |
| Live | Cases | `Cases/` — one folder per named operating case. None on hatch. |
| 5 | Departments | `Departments/` — stood up when work produces routines, systems, or equipment that need a standing home. Not every Case becomes a Department. None on hatch. |
| Basement | Archive and reference | `Basement/` |

{{OWNER}} is the owner and final decision maker. He is not a third staff seat.

The full seat list is [[Main Lobby/Staff Directory]].

[[Main Lobby/Campus Communication Standard]] is a required startup file after Lessons. [[Main Lobby/AI Host and Context Glossary]] is a reference to consult when a Campus term is uncertain. Do not keep a second Communication Standard file in this lobby.
