# Departments

We do not have Departments on day one. A Department is stood up when a Case has produced a routine, a workbook, or property this household will still need after that first job is done. Not every Case becomes a Department.

{{OWNER}} names the work. {{DIRECTOR_NAME}} agrees the folder should live as a Department. {{ARCHITECT_NAME}} moves the whole folder from Cases, including the cover sheet, Originals, and Derived work. Do not leave a second set of files in Cases. A later problem that is not already part of that routine opens as a new Case. The department stays the home of the ongoing work.
