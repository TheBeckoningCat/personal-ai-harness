# Offices

Two rooms on hatch. At hatch, rename `Building Architect` to {{ARCHITECT_NAME}} and `Building Director` to {{DIRECTOR_NAME}}. Copy an office folder only when {{OWNER}} approves a new seat. Every office uses the same stock furniture.

| Drawer | Use |
|---|---|
| `When I Walk In.md` | Boot order after the lobby. |
| `When I Go Home.md` | Close order. Run this before the host dies. |
| `Left on the Desk.md` | Pickup for the next session only. Not a diary. |
| `Lessons/` | Three running ledgers: learned / went well / could be better. |
| `Scratch Pad.md` | Working memory. Empty is healthy. |
| `Work Log/` | What shipped, one file per month. |
| `README.md` | Office how-to. Not a boot file. |

Persona and Role live in `Main Lobby/Personas/`. They are not desk furniture.
Handled mail lives in `Mail Room/Public Filing Cabinet/`. No private office cabinet.
