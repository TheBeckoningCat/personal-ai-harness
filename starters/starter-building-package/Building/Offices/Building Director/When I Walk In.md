# When I Walk In - Building Director

How I start a session after the lobby. Change this list if a step wastes time.

How this office works: [[README]]. That is not a boot step.

Closing: [[When I Go Home]]. Do not run that list until you are done.

1. Read [[Left on the Desk]]. That is yesterday's pickup. It says what to open first.
2. Do not open [[Scratch Pad]] or the mailbox yet.
3. Read [[Mail Room/Message Board]]. Answer anything to the Building Director or @All on the board.
4. Check [[Inbox/README|Inbox]]. Process every file. If it belongs in a Case or Department, move it to that `Originals/` folder. If this Building might need it later and it has no live home, move it to the Basement. Nothing stays there except the README. Do not treat Inbox as current state.
5. Conference Room: read [[Conference Room/How We Talk]] before you write Talk. Glance The Docket for names only. Do not discuss a parked sheet. Then read every live Table Topic.
6. Open [[Scratch Pad]] only if [[Left on the Desk]] says to.
7. Last: mail. Open [[Mail Room/Town Hall Connection]]. Town Hall mail is standing only after that sheet is fully configured and the hatch proof passed.

   Go to the Director's assigned Town Hall role box named there. Pull every packet for this Building into `Mail Room/Mailboxes/Director`. After hatch that folder carries the Director's name. Verify that each local copy opens and is complete, then clear the source copy. Nothing stays in the transit mailbox once it has been pulled.

   A packet is a work slip: a ticket-like request from {{OWNER}}, another Building, or a central system. It is mail, not a dump, and not a local project note.

   Confirm the slip has the minimum information needed to act:

   | Field | Meaning |
   |---|---|
   | Type | Work Slip, Project Candidate, Return, Accepted Commitment, Waiting For, Date, or Blocker |
   | Outcome or work | The decision, consequence, or concrete request |
   | As-of / deadline | Include only when freshness or timing matters |
   | Authorized source | Local source, deliverable, or source ticket the receiver may use |

   Do the work here, in this Building's files. Do not copy the slip into a second local action list. Do not open or write the originating ticket unless {{OWNER}} explicitly grants that access.

   If the slip is unclear, ask {{OWNER}} or send one question to the named sender or curator through the assigned mail route. Do not invent a second project.

   Then handle notes already in your local mailbox, including findings or Project Candidates routed locally by specialists. Specialists do not pull Town Hall mail. File or archive finished notes in the local mail system if this Building has that drawer.

8. If this list was wrong, edit **this file** - not the persona.
