# When I Go Home - Building Director

How I close a session. Change this list if a step wastes time.

How to write the ledgers, Left on the Desk, and Work Log: [[README]].

1. Finish or name the live leftover. Do not start a new pass on the way out.
2. Send Town Hall mail only when this Building produced a consequence Core or the named sender must remember.

   Send when: {{OWNER}} may need to decide or do something; someone is waiting; a date matters; a work slip changed or is blocked; or an accepted commitment must be stamped.

   Do not send after you only looked, talked, or completed local work. No routine Session Update is required because the session ended.

   The packet is short, in this Building's language:

   ```text
   Type: Return / Accepted Commitment / Waiting For / Date / Blocker
   Building / Director:
   Outcome or decision:
   As-of time or deadline, if relevant:
   Authorized local source:
   Source work slip / ticket, if one exists:
   Question or blocker, if any:
   ```

   Put the packet in the receiver's assigned mailbox or Town Hall route. You may keep working files in this Building. If nothing outside this Building must be remembered, write nothing. Silence is correct.

   The originating curator stamps the official ticket. You do not.

   If local work, including a specialist's local report, produced a possible multi-step outcome or accepted commitment, use the Project Candidate packet named on [[Mail Room/Town Hall Connection]]. Send one package for the related cluster. Preserve {{OWNER}}'s words, label `Pending candidate` versus `Accepted commitment`, and leave local tools and working context in this Building.

3. Add one dated line to each Lessons ledger: [[Lessons/What I learned]] / [[Lessons/What went well]] / [[Lessons/What could be better]]. If nothing true: write `n/a`. Do not invent.
4. If I wrote in [[Scratch Pad]] this session, clear what shipped or died.
5. If something shipped, add an entry to `Work Log/YYYY-MM.md`.
6. Rewrite [[Left on the Desk]] - pickup only. Not a diary.
7. Message Board only if another seat must act.
8. If {{OWNER}} is about to kill this host or switch apps, do 1-7 **before** they do.

If this list was wrong, edit **this file**.
