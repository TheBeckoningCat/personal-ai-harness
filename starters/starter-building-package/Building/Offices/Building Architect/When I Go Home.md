# When I Go Home — Building Architect

How I close a session. Change this list if a step wastes time.

How to write the ledgers, Left on the Desk, Work Log, and how to clear scratch: [[README]].

1. Add one dated line to each Lessons ledger: [[Lessons/What I learned]] · [[Lessons/What went well]] · [[Lessons/What could be better]]. If nothing true: write `n/a`. Do not invent.
2. If I wrote in [[Scratch Pad]] this session, clear what shipped or died.
3. If something shipped, add an entry to `Work Log/YYYY-MM.md`.
4. Rewrite [[Left on the Desk]] — pickup only. Not a diary.
5. If an architecture work order is done, waiting, blocked, or changed a shared edge another Building depends on, send one short return packet to the named architecture sender. For campus architecture that your vault architect (optional campus seat) must coordinate, use the exact Architect route on [[Mail Room/Town Hall Connection]] when Town Hall is wired. Name the packet type, outcome, relevant as-of time or deadline, authorized local source, and any blocker or requested next action. Do not send ordinary local housekeeping or a routine Session Update.
6. If architecture work produced a possible commitment for {{OWNER}}, route it locally to the Building Director. The Director owns the Project Candidate route to your campus operations secretary when that campus seat exists. Do not turn an architecture recommendation into an accepted commitment.
7. Tell the Board only if another local seat must act.
8. If {{OWNER}} is about to kill this host or switch apps, do 1–7 **before** they do.

If this list was wrong, edit **this file**.
