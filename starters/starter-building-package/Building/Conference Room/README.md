## Rules

1. One active topic on the Work Table.
2. A topic must come from The Docket onto the Work Table before Talk starts.
3. Anyone may add a request sheet to The Docket.
4. {{OWNER}} names which sheet is live. The Director keeps that choice aligned with the mission.
5. How we write: [[How We Talk]]. Newest first. Signed. Do not rewrite another person's words.
6. After {{OWNER}} marks Finished, then File or Delete. Usual mark is Delete. File parks that sheet on The Docket.
7. `@Name` or `@all` means that person must act. A doorbell stuffs See Work Table for new updates and comments. Doorbells do not write vault files. The working named persona writes Talk.
