# Public README — Building Starter Package

This package is a **hatch checklist + Building skeleton**. It is **not** a one-click AI Campus.

## Beta

This starter is a **beta / betta-test** public release. Expect rough edges. The primary success path is the chatbot / paste path below. Optional Mac `.command` helpers and First Run installer templates (if offered later) are optional beta helpers — not required.

## Chatbot / paste path

Load this starter by pointing an AI at the files **or** dragging them into a chatbot (ChatGPT, Google AI / Gemini, and similar).

Many chatbots cannot upload a whole folder. If folder upload fails, **drag files in batches** (or paste one file at a time, starting with `START HERE.md`). Ship content for that path is **markdown / text only**. Obsidian `.json` configs under `.obsidian/` may be present and are optional. You do not need images, audio, or a `.command` file to succeed.

The AI’s first visible reply should print the © / use notice (see `USE NOTICE.md`), then continue warmly.

## First run

1. Download the zip and unzip it.
2. If the chat can take a folder: drop this folder and say **Start Here** or **go**.
3. If the chat can only take one file (free Gemini and similar): paste `START HERE.md` first, then say **Start Here** or **go**. The guide will ask for the next file by name.

The AI’s first reply should be the copyright / use notice, even when that is the only file it has.

## What you get

- A stacked-office Markdown tree (Main Lobby, Inbox, Cases, Offices, Mail Room, Conference Room, Departments, Basement)
- Two seats on hatch: **Architect** (structure) and **Director** (mission / local work)
- Boot loop files, Role/Persona templates, talk templates, and a Town Hall connection sheet
- Placeholders you fill once (`{{OWNER}}`, `{{BUILDING_NAME}}`, paths, seat names)

## What this is not

- Not a finished multi-Building AI Campus
- Not a product that silently runs email or calendar for you
- Not a GTD clone and **not branded as GTD**. Getting Things Done (David Allen) may be cited as an influence on review and next-action thinking; this vault language stays Building / Case / Work Table.
- Not a requirement to use AI. Markdown is the store of record. You can run the whole Building with a text editor and no model.

## How to view these files

A Domain / Building is a folder of `.md` notes (ordinary text). This release was written in **Obsidian**, free for personal use and not required. See `How to open these notes.md`.

Download Obsidian from the real site: [https://obsidian.md/download](https://obsidian.md/download) (home: [https://obsidian.md](https://obsidian.md)). In Obsidian choose **Open folder as vault** and pick the `Building` folder. Any text editor works if you skip Obsidian.

## How to use

1. Prefer **First run** above (`START HERE.md`).
2. Read [[HONEST_LIMITS]]
3. Follow [[How to Hatch a New Building]] for the manual checklist
4. For a **solo Building**, skip Town Hall wiring until you have a campus meeting house
5. After first-run, boot each seat from `Main Lobby/Start Here.md`

## Honesty

A hatch is multi-step. Obsidian is recommended; any Markdown folder works. Personas are shells you fill. Review rhythm is your job.
