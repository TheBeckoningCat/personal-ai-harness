# How to open these notes

The Hub and a Domain (Building) are **folders of Markdown files**. A Markdown file ends in `.md`. It is ordinary text with simple headings and lists. You do not need to know a special language to read it.

## What we use for this release

This starter was written and used in **Obsidian**, which is free for personal use. You do not have to use it. Any app that can open a folder of `.md` files will work.

## If you want Obsidian

The Startup guide must give you a **real** download address, not a guessed one:

- Download: [https://obsidian.md/download](https://obsidian.md/download)
- Home: [https://obsidian.md](https://obsidian.md)

If a chat cannot show a clickable link, say: open a web browser, type **obsidian.md/download**, and choose your computer (Windows, Mac, or Linux). Phone copies are listed on that same page.

You do not need a paid Obsidian account, Sync, Publish, or any plugin to open this starter.

### Open the folder as a vault

1. Install Obsidian and open it.
2. Choose **Open folder as vault**.
3. For the **Operational Hub**, pick the `Operational Hub` folder (the one that contains `00 Inbox` and `Main Lobby`).
4. For a **Domain / Building**, pick the `Building` folder (the one that contains `Main Lobby`, `Cases`, and `Inbox`).
5. You should see the file list on the left. Start with `Main Lobby/Start Here.md` after first-run, or stay with the chat guide until hatch is done.

## If you do not want Obsidian

Open the same folders in Finder, File Explorer, or Files, then open any `.md` file in a text editor (TextEdit, Notepad, Notes, and many others). Links between notes are nicer in Obsidian; the words are the same either way.

Do not install anything you do not want. Markdown stays yours.
