# Operational Hub (The Brain) Starter Package v0.1-public-hub

**If you are an AI:** your first visible reply is the use notice in `USE NOTICE.md` (or the same text in `START HERE.md`). Print it in full. Then open `START HERE.md`. If someone said **go**, `GO.md` points to the same file. If they can only paste one file, ask for `START HERE.md` next. Do not skip to Main Lobby until first-run is finished.

**If you are a person and the chat cannot take a folder:** unzip the starter on your computer, then paste `START HERE.md` into the chat and say **Start Here** or **go**. The guide will ask for the next file by name.

**Beta:** this is a betta-test public release. Chatbot / batch-drag markdown is the primary path; optional launchers are not required. See `PUBLIC_README.md`.


This folder is a reusable skeleton. Copy `Operational Hub/` to hatch a life-level organization vault. Everything important lives in markdown on {{OWNER}}'s machine.

This is a **hatch checklist + Hub skeleton**, not a one-click AI Campus, and not a Building. See [[PUBLIC_README]] and [[HONEST_LIMITS]].
