# Design rationale — Operational Hub v0.1-public-hub

## 1. Hub vs Buildings

The Operational Hub (The Brain) is the life-level store of record: capture, clarify, organize, reflect, engage. Domain **Buildings** are extensions — stacked offices for one Area of Life or domain. Buildings do not replace the Hub's next-action and review system; they extend it.

| Layer | Job |
|---|---|
| Operational Hub | Life-level inbox, projects, areas, daily/journal, Core seats, review |
| Domain Building | Mission, Cases, Departments for one domain; may send consequence mail toward the Hub |

## 2. Why these floors

| Floor | Job |
|---|---|
| `00 Inbox/` | Unsorted capture. Not current state. |
| `10 Projects/` | Active project notes with Next / Planned / Waiting For |
| `20 Areas & Contexts/` | Approved Areas of Life and Context vocabulary |
| `30 Resources/` | Stable reference shelf (empty on hatch) |
| `40 Archive/` | Closed work |
| `50 Someday-Maybe/` | Not now |
| `Daily/` | Day overview and short capture |
| `JournalEntries/` | Morning/evening reflection |
| `Calendar/` | Optional Markdown calendar for real-world dated events |
| `Templates/` | Insertable forms |
| `Main Lobby/` | Shared static boot, map, access, communication standard |
| `70 Strategy & Operations/` | Offices, Mail Room, Conference Room, Core SOP, Control Room |

## 3. Dual Core seats

Hire a job, not a personality.

- **Operations Secretary** — processes Inbox and Daily, keeps projects and next actions honest, runs review rhythm
- **Vault Architect** — owns folder tree, SOPs, Access Boundaries, and structural change

{{OWNER}} makes final decisions. Role/Persona files in the lobby are **shells** to fill after hatch.

## 4. Markdown is the store of record

Chat is temporary. Agents reboot. Hosts do not share a brain. Role, Persona, When I Walk In, When I Go Home, Lessons, and Left on the Desk make a seat persistent-like without a vendor memory product.

## 5. Review is the product

The Hub is useful only if {{OWNER}} reviews. Daily, weekly Projects Base glance, and clearing Inbox are human work. Boot loops help habit; they do not run themselves.

## 6. Usable without AI

Every floor works with a text editor. AI seats are optional operators, not a requirement. If a host is unavailable, the Markdown remains.

## 7. Influence, not brand

Capture, next actions, contexts, and review will feel familiar if you already practice Getting Things Done (David Allen) or similar methods. Do not brand this Hub as a GTD product. Keep official tickets wherever you already keep them.
