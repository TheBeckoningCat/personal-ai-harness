# Contexts

How it works: [[70 Strategy & Operations/Core SOP/Areas/Areas and Contexts]]

Approved vocabulary for Next Action lines only. **Replace with your own after hatch.**

Examples:

- `[ ] [WITH Vault Architect] Ratify the Areas and Contexts design.`
- `[ ] [Computer] Test the Projects Base.`
- `[ ] [WITH Operations Secretary] Normalize the approved Area vocabulary.`

## Approved Contexts

### Place / mode

| Context | Use |
| --- | --- |
| Desk | Physical desk work |
| Computer | General computer (not email-only) |
| Phone | Calls / phone-first tasks |
| Email | Email processing, writing |
| Shopping | Errands / stores / online stores |
| Outside | Around the city and neighborhood |
| Around the House | Home physical tasks |
| Work Table | Done sitting at the Conference Room table |
| Workplace | At the workplace |

### WITH (people / agents)

| Context | Use |
| --- | --- |
| WITH Household Partner | Needs a household partner |
| WITH Operations Secretary | Needs the Operations Secretary |
| WITH Vault Architect | Needs the Vault Architect |
| AI Assistance | Generic AI help (no named persona) |
