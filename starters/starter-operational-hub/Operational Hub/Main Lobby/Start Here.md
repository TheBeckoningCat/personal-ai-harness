## Rules for starting a session

1. Start a new session with a **boot line** above.
2. If {{OWNER}} does not name a Core seat, do not continue. There is no default identity.
3. One persona per session unless you explicitly switch.
4. Follow that office's `When I Go Home.md` before ending the session or switching hosts.
