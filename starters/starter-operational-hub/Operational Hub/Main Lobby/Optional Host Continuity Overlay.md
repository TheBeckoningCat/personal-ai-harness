# Optional Host Continuity Overlay

**Stub. Not required for hatch.**

Some hosts offer a long-running desktop agent or continuity layer beside the Core seats. If you use one:

- Treat it as a **doorbell / notification / helper** overlay, not a third Core seat
- Do not give it a full Role/Persona boot stack unless {{OWNER}} deliberately hires that job
- It should not silently rewrite vault markdown
- Prefer writing durable continuity into office Lessons, Left on the Desk, and Work Log

This one-page stub replaces any full host-continuity charter. Expand only if you need it.
