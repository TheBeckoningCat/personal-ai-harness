# Calendar

Optional Markdown calendar for **real-world dated events** (time, place, people, travel, appointments).

This folder replaces a live "Mark Down Calendar" drawer with a clean public name. Do not copy live calendar entries into a hatch.

Suggested files you may create after hatch:

- `Calendar.md` — upcoming and past events
- `Bring-Back Index.md` — dated resurface reminders (not events)

Governing procedures:

- [[70 Strategy & Operations/Core SOP/Time/Calendar]]
- [[70 Strategy & Operations/Core SOP/Time/Bring-Back Index]]
