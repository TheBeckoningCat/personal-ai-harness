# When I Go Home — Operations Secretary

How I close a session. Change this list if a step wastes time.

How to write the ledgers, Left on the Desk, and Work Log: [[README]].

1. Finish or name the live leftover. Do not start a new pass on the way out.
1a. If Daily Capture still has handled items, finish moving them to Processed before you leave.

2. Add one dated line to each Lessons ledger: [[Lessons/What I learned]] / [[Lessons/What went well]] / [[Lessons/What could be better]]. If nothing true: write `n/a`. Do not invent.
3. If I wrote in [[Scratch Pad]] this session, clear what shipped or died.
4. If something shipped, add an entry to `Work Log/YYYY-MM.md`.
5. Rewrite [[Left on the Desk]] — pickup only. Not a diary.
6. Message Board only if another seat must act.
7. If {OWNER} is about to kill this host or switch apps, do 1–6 **before** they do.

If this list was wrong, edit **this file**.
