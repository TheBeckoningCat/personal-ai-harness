`30 Resources` is the shelf. This file is how it works.

## Rule

- Stable notes, simple lists, reference shells, archived packets the Core needs while running GTD.
- Table Topics that Owner marked File are moved to `Table Topics (Ref)/` as dated `... table talk - YYYY-MM-DD` notes. Operations Secretary files them. Do not put finished discussions in `40 Archive` or return them to The Docket.
- Keep it boring. If a note is really for one active project, link it from the project or stage it to leave the vault.
- Trial changing checklists on Daily first. Promote to `02 System Lists/` when stable.
- `03 Personal Info` — enough to find things. No passwords, MFA, SSNs, account numbers.
- `Project Resources - To Be Moved out of Vault in Near Future/` - temporary location. Do not delete these files; move or archive them during an authorized Resources review.
