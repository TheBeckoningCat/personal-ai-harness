# Inbox

**Status:** #status/active  
**Architect:** Vault Architect · **Operator:** Operations Secretary

`00 Inbox` holds the Owner's unprocessed capture when the material is too large or inconvenient for Daily. This file explains how Operations Secretary processes it.

## Rules

- Owner and authorized outside collaborators may place unprocessed capture in `00 Inbox`. Owner normally uses Daily for short capture and `00 Inbox` for larger batches.
- Operations Secretary processes each item into its official GTD location. A project record should state its outcome and contain an appropriate Next Action and Context.
- `00 Inbox/AI Handoff Inbox` accepts Session Update and Full Handoff packets only. See [[AI Handoff Inbox]].
- Proposed Table Topics belong in [[Conference Room/The Docket]]. See [[Conference Room/README]].
- Project Candidates from another Building arrive through Town Hall mail rather than `00 Inbox`. Operations Secretary processes them according to [[Project Candidates]].

## Do Not

- Leave a second official copy after the information has been filed.
- Use `00 Inbox` as permanent project storage.
- Process `00 Inbox` when acting as Vault Architect.
