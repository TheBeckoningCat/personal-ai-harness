# Calendar

**Status:** #status/active  
**Architect:** Vault Architect · **Operator:** Operations Secretary  

[[Calendar/Calendar]] is the list of events. This file is how it works.

## Rule

- Real-world dated events only — time, place, people, travel, appointments.
- Not the resurface system. That is [[Bring-Back Index]].
- One line: `YYYY-MM-DD - What / where / who. Source: [[link]]`
- Optional time: `YYYY-MM-DD HH:MM`
- When it is over: move to **Past Events** with a one-line outcome, or archive with the project.

## Do not

- Copy project lists here.
- Put “remind me later” here. That is Bring-Back.
