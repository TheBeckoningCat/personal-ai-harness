# Projects Base

**Status:** #status/active  
**Architect:** Vault Architect · **Operator:** Operations Secretary  

[[70 Strategy & Operations/Projects.base|Projects Base]] is the project inventory. The separate Project Dashboard file has been deleted.

## Rule

- Project notes in `10 Projects` remain authoritative.
- Operations Secretary keeps `area`, `status`, `priority`, and `review-on` true on those notes so the Base stays current.
- Do not maintain a second curated list of live projects.

## When Operations Secretary updates it

- When a project is created, moved, closed, or deleted, set or confirm the properties. The Base follows the notes.
- Open the project note for Next Actions. Do not treat the Base as the contents of the work.

## Do not

- Recreate Project Dashboard.
- Copy Next Actions into the project inventory.
