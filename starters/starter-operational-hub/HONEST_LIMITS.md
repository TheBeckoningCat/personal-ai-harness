# Honest Limits

Read this before you treat the starter as a finished AI Campus or a finished brain.

## Hatch is multi-step

Copying the folder is not the finish line. You still replace placeholders, fill Role/Persona shells, set Access Boundaries, and write your Areas list. Expect a working afternoon, not a one-click install.

## Obsidian is recommended, not required

This release was written in Obsidian, which is free for personal use. Download it from https://obsidian.md/download if you want it. Any folder of Markdown files works. You do not need a paid plugin stack. See `How to open these notes.md`.

## Personas are shells

Operations Secretary and Vault Architect files are starting shapes. Voice, judgment, and Lessons grow from use. This package does **not** ship finished character portraits or live Work Logs.

## No silent email or calendar control

Nothing in this package grants automatic control of your real mail, calendar, or phone. Access Boundaries require {{OWNER}} approval before those surfaces are touched. Hub "mail" here means Markdown packets between vault folders.

## Review rhythm is yours

Daily, Inbox clearing, Projects Base glance, and Weekly review stay human work. The boot loop helps; it does not run itself.

## Hub is not a Building

This package is the life-level Operational Hub. Domain Buildings are a separate starter. Do not expect Cases/Departments floors here; those belong in Buildings.

## Influence, not brand

If you already practice Getting Things Done (David Allen), some ideas will feel familiar. Do not brand this Hub as GTD. Keep your own vocabulary if you prefer another personal organization method.

## Launchers are optional templates

This package does not include runnable `.command` or `.bat` files. If you want a double-click starter, the Startup guide can fill one template from `launcher-templates/` for your computer. Those files assume a program you already have. They are not a licensed product installer and they are not required for first-run.
